# HelpDeskPro – SaaS Ticket & Incident Management System

## 📌 Project Overview
HelpDeskPro is a full-stack SaaS Ticket & Incident Management System developed using React, Flask, and MySQL. The platform helps users raise support tickets, track issue progress, and communicate with support teams, while admins and support agents manage ticket resolution, SLA monitoring, and customer support workflows through a centralized dashboard.

This project is designed to simulate real-world SaaS product support operations used in companies for handling customer issues efficiently.

---

## 🚀 Features

### 👤 User Features
- User Registration & Login
- Create Support Tickets
- Select Ticket Priority & Category
- Track Ticket Status
- View Ticket History
- Add Comments & Responses

### 🛠️ Support Agent Features
- View Assigned Tickets
- Update Ticket Status
- Resolve Customer Issues
- Add Internal Comments
- Manage Ticket Priorities

### 👨‍💼 Admin Features
- Dashboard Analytics
- Monitor Open & Resolved Tickets
- Manage Users & Support Agents
- SLA Monitoring
- Track Overdue Tickets

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/neeraja00/helpdeskpro-ticket-management-system.git
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
pip install -r requirements.txt
python app.py
```

---

## 🗄️ Database Setup

Create MySQL database:

```sql
CREATE DATABASE helpdeskpro;
```

Import the `schema.sql` file from the database folder.
